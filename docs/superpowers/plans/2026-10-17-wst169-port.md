# WST169 (Touch-LCD-1.69) Port, Phase 1 (USB) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pocket Tank runs on the Waveshare ESP32-S3-Touch-LCD-1.69 over USB as a sixth board, `CONFIG_POCKET_TANK_WST169`, with a 280×240 landscape tank.

**Architecture:** WST169 joins the fork's small-board family: its Kconfig entry `select`s the existing `POCKET_TANK_320X240`, so it gets the 292×240 page, no OTA, the SLEEP row, landscape touch and light sleep. A second symbol, `CONFIG_POCKET_TANK_WST169`, is passed to `common/` and overrides only what depends on width: `TANK_W`, the algae grid, the three whole-glass page layouts and the old CYD save read-back. Firmware reuses `display_port_spi.c` (ST7789) and the Touch-LCD-2's CST816 touch path with the 1.69's pins.

**Tech Stack:** C11, ESP-IDF v5.5.2 (`~/esp/v5.5.2/esp-idf`), esp_lcd ST7789 + esp_lcd_touch CST816S, LVGL v9.2.2 + SDL2 simulator, Python 3 tools.

**Spec:** `docs/superpowers/specs/2026-10-17-wst169-port-design.md`

## Global Constraints

- The sim on this Mac is built with `make ARCH=`, because Homebrew's SDL2 is arm64.
- Follow the fork's style: dated `(this fork, 2026-10-17)` comments that say *why*, redefine upstream names inside the fork's own blocks, and leave upstream lines as they are.

## Review Focus

1. **Other boards regress.** Changes to the shared `POCKET_TANK_320X240` family leak into the CYD and WST. Tasks 1, 3 and 4 run `check-all`, then build WST and default.
2. **Taps near the edges and corners.** On a 280 glass, a tap at x 270..279 must reach the right-hand buttons, and none of them may sit under the rounded corner. Task 3's static asserts cover this; Task 6 checks it with a finger.
3. **A save written at 280.** The 168-cell algae grid saves and loads within the 644-cell save storage. Task 1 runs `--selftest-saves` in the 280 world.
4. **Picture turned 180°.** The gap stays right after a flip. Task 5 has a bench step for it.
5. **Light-sleep wake.** The reset pins (GPIO 8, 13) are held through the dark, so a touch wakes the tank and does not reset the chip. Task 6 has a bench step for it.
